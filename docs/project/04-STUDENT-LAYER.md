# طبقة الطالب

## الموجود

- `/student/login/`: تسجيل/إنشاء حساب بالبريد وكلمة المرور.
- `/student/auth/callback/`: إتمام PKCE وتأكيد البريد بوجهة ثابتة.
- `/student/`: التحقق من المستخدم، عرض البريد، الملف الشخصي والخروج.
- `/student/profile/`: قراءة وتعديل `display_name`.
- الصفحات `noindex` ومستبعدة من sitemap.

جدول `profiles` مرتبط بـ`auth.users` مع trigger للإنشاء وRLS للمالك. تصلح الواجهة صفًا مفقودًا لحساب قديم ضمن RLS.

## تقدم الدرس

- الزائر: `localStorage` بالمفتاح `alkulify:student:lesson-progress:v1` وحقل `videoId`.
- المسجل: `lesson_progress` بالمفتاح `(user_id, lesson_key)`.
- عند الدخول يدمج التقدم المحلي ثم يحذفه بعد نجاح النسخة نفسها.
- الكتابات متسلسلة في مثيل المشغل؛ RPC يستخدم `greatest` وOR ويمنع تغيير المالك.
- القيود ترفض القيم غير الصالحة والمدد فوق سنة والموضع المتجاوز للمدة.

## غير الموجود

لا توجد قائمة تقدم، تجميع على مسار، مسح/إعادة ضبط، مزامنة للملاحظات أو المحفوظات، أدوار إدارية، أو تفضيلات دراسة.

## قواعد التوسع

تبقى بيانات المستخدم مملوكة عبر RLS، والعلاقات التعليمية تستخدم `lesson_key`. كل مزامنة جديدة تحتاج سياسة تعارض واختبارات offline/race، ولا يصبح الحساب شرطًا لقراءة الأرشيف.
