# مسارات الدراسة

## الحالة

لا توجد ميزة أو جداول أو صفحات مستقلة للمسارات. الموجود فقط: قوائم تشغيل مرتبة، تنقل سابق/لاحق، هوية `lesson_key`، وتقدم لكل طالب/درس. لا تُعد قائمة التشغيل مسارًا تلقائيًا؛ قد تكون تصنيفًا بلا هدف أو متطلبات.

## النموذج المطلوب

- مسار: هوية وعنوان ووصف وحالة نشر وإصدار.
- وحدة: ترتيب وهدف تعلم.
- عنصر: `lesson_key` وترتيب.
- تسجيل طالب: وقت البدء والحالة.
- تقدم مسار: مشتق أو محفوظ وفق سياسة معلنة.

## قرارات مفتوحة

هل تعيش المسارات في Git أم قاعدة البيانات؟ ما تعريف الإكمال؟ ماذا يحدث عند تغيير إصدار المسار؟ وهل تستورد قوائم YouTube مرة أم تبقى متزامنة؟

## الترتيب المقترح

تثبيت عرض تقدم الدروس، ثم اعتماد schema بإصدارات و`lesson_key`، ثم صفحة قراءة، ثم التسجيل والتقدم، وأخيرًا أدوات التحرير.
