# رؤية المشروع

## الغرض

تحويل أرشيف الشيخ أبي جعفر عبد الله بن فهد الخليفي إلى بيئة معرفة ودراسة عربية: بحث موثق في الدروس والمقالات، ثم طبقة طالب تحفظ الهوية والتقدم، ثم مسارات دراسة وإجابات مسندة إلى المحتوى.

## القيمة الحالية

- أرشيف Astro ثابت، عربي وRTL، للدروس والمقالات والقوائم.
- بحث حرفي ودلالي عبر Meilisearch، مع فتح الفيديو عند موضع النتيجة.
- حساب طالب وملف شخصي وحفظ تقدم محلي/سحابي عبر Supabase.

## الاتجاه والمبادئ

يبقى المحتوى العام سريعًا ومتاحًا بلا حساب، وتضاف بيانات الطالب في حدود متغيرة ومعزولة. Git والكود والبيانات هي مصدر الحقيقة. تستخدم العلاقات `lesson_key` المحايدة لا معرّف مزود المحتوى. وكل جواب بحث أو ذكاء اصطناعي يجب أن يقود إلى مصدر قابل للتحقق.

الترتيب المقصود: تثبيت التقدم وعرضه، ثم مسارات الدراسة، ثم «اسأل الذكاء الاصطناعي». لا توجد حاليًا مسارات مُدارة أو واجهة سؤال/جواب.
